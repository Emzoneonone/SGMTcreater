## 一键文件

| 文件 | 作用 |
|---|---|
| **AGmaster1.8beta一键安装.cmd** | 安装到 `D:\aiLOCAL\comfy-panel` |
| **AGmaster1.8beta一键还原.cmd** | 用本备份覆盖回插件目录 |

## 工作台说明

- 底图来源：**生成页的结果**（不取局部修复结果）
- 「使用这张图」把底图载入为 i2i 输入
- 微调参数独立于生成页，避免互相干扰
- 进度条与生成页共用任务轮询
