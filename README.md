（zhCN）
SGMTcreater的初衷是为了简化麻烦的生成式ai的流程图，替代以简单明了的图形化操作界面，该插件为面向Deepseek Harness的拓展插件.
#注意！全部程序是在windowsx86_64环境下构建的，不保证包括Ubuntu在内的Linux系统上运行的可能性
包含的界面程序：生成页，修复页，高清修复，工作台，模型，管理，提示词与画风，帮助页，还有系统页面，请严格按照既定的指南来修改或者开发变体版本
项目包括
1.主程序（Main）
2.一键安装程序脚本(winBat)
3.一键还原程序脚本(winBat)
4.README.md副本
5.图标程序
6.程序组件
